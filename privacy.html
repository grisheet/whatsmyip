Privacy

GitHub hosts this page and may log requests for it under its privacy policy. The application does not set cookies or use analytics.

Lookup requests

Your browser looks up the address you enter using public data files served by GitHub Pages. The file path identifies a network range. The full address you enter stays in your browser.

When you press “Use my IP”, your browser asks ipify for its connection address. ipify receives that address. The location lookup then runs with the same public data files. Opening the page alone sends no request to ipify.

The site does not save lookup history. Your browser can cache data files as it would other website assets.
